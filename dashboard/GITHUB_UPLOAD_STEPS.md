# GitHub Upload Steps

Create a repository named `atmosync-microclimate-arbitrage`.

From the project root:
```bash
git init
git add .
git commit -m "feat: complete AtmoSync analytics project with BI dashboard"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/atmosync-microclimate-arbitrage.git
git push -u origin main
```

Replace `YOUR_USERNAME` with your GitHub username.

Future updates:
```bash
git add .
git commit -m "feat: update AtmoSync dashboard"
git push
```
